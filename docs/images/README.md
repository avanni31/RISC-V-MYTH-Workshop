# Workshop Evidence

This folder contains screenshots/results supplied from the workshop work.

The screenshots are kept as evidence of the hands-on progression and can be linked from the day-specific documentation when the exact exercise represented by a screenshot is known.

## Why they are included

A technical portfolio is stronger when it shows both:

1. the source code and documentation, and
2. evidence of the design being worked on / simulated.

The screenshots are therefore preserved separately from the source code so the repository remains organized.
